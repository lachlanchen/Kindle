GOOD QUESTIONS

Nothing hidden.

Why is USB needed once?

The first USB connection safely places this computer's public key into KOReader. The private key never leaves the computer. Later transfers are wireless.

Does the app upload my books?

No. Discovery and transfer happen directly between your computer and Kindle on the local network. The app has no account or telemetry.

Why must KOReader SSH be started?

It gives the app a temporary, authenticated path to the Kindle. Stop the server after sending if you no longer need wireless access.

What if discovery finds nothing?

Confirm the same Wi-Fi, open KOReader and start Tools → SSH server. Pair again by USB if this computer has never controlled the Kindle. A manual IP field remains available as a fallback.

Which books are supported?

KOReader handles PDF, EPUB, MOBI, AZW3, DJVU, CBZ, CBT, DOCX, RTF, HTML, TXT, FB2, XPS, Markdown and other common formats.

Is this an Amazon product?

No. Kindle Book Sender is an independent open-source utility for personally owned devices running KOReader.
