# Kindle Jailbreak Assistant 0.1.0

First public cross-platform release from LazyingArt.

- Windows x64 executable
- Linux x64 and ARM64 binaries
- macOS Intel and Apple Silicon applications
- Live official Kindle model matrix and refreshable compatibility catalog
- SpringBreak helper integration
- Safe payload staging for Sanctuary guidance, Nosebleed, AdBreak, WinterBreak2, WinterBreak, and the universal hotfix
- Legacy and hardware-route guidance
- Reversible OTA space guard and per-operation backups

Jailbreaking can void a warranty, create security risks, or brick a device. The assistant stops on unsupported combinations and does not replace each method's authoritative guide.
